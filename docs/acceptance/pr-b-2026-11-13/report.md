## 1. 做法：先量，再改

没有凭“看起来像”调样式。每一处改动都来自对参考图的像素测量，并且把测量写成了门禁：

| 量什么                     | 怎么量参考                             | 参考值                | 我们（改前 → 改后）                              |
| -------------------------- | -------------------------------------- | --------------------- | ------------------------------------------------ |
| 侧栏宽度                   | 分隔线所在列                           | 259px                 | 259px → 259px                                    |
| Composer 外框              | `#ffffff` 连续区间，1px `#dbdbdb` 边框 | 766×50 @ y=421        | 766×52 → 766×52（边框差异在容差内）              |
| 欢迎标题                   | 深色像素行带                           | 17px 字高 / 28px 行高 | 一致                                             |
| 标题到 Composer 的上沿间距 | 文字底 382 → 框顶 421                  | 39px                  | 16px → **32px**（文字底到框顶 33px，在 39±6 内） |
| 侧栏导航行距               | 图标列像素分组中心                     | 34–38px               | 43/37/48 → **38px**                              |
| 代码块                     | 参考中带语言标签与复制按钮             | 有                    | **原先语言标签在块外、无复制按钮**               |

## 2. 修了什么

| #   | 问题                                               | 根因                                                                                  | 修复                                                                                                          |
| --- | -------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |

## 3. 新增门禁 `check:ai-workbench-visual`

20 项断言，全部通过：

- C01 空态：侧栏宽、Composer 宽高、标题单行 28px、标题↔输入框节奏、导航行距；
- C03 对话：同样三项几何 + **回答确实渲染成 Markdown**（轮询到 `pre` 出现）；
- C05 深色：三项几何 + 主题真的是 dark；
- C07 模型菜单可打开、C06 设置是页面而非弹层、C04 焦点态可辨识；
- C08 移动端：390×844、无横向溢出；
- 全程无页面异常。

同时产出 **参考｜实现 并排对照图**（`screenshots/`），这是“真实截图对照”的交付物；门禁只锁几何，颜色与观感由人看并排图判断。

## 4. 与参考的有意差异

这些不是缺陷，写在此处以免被当成漏项：

| 差异                                     | 原因                                                                  |
| ---------------------------------------- | --------------------------------------------------------------------- |
| 顶栏是「模型选择器（Agent / 我的模型）」 | 产品有双模式；参考是单一模型。命名与位置按 ChatGPT 的模型选择器形态做 |
| 侧栏底部是账号信息                       | 有真实会话用户；参考的推广卡是未登录营销位                            |
| 侧栏有 Search chats（占位）              | 参考的搜索属于会话检索，留给后续；当前不假装可搜                      |
| 无登录/注册按钮                          | 本产品无账号体系                                                      |
